Overview & Roles

System Designer Animation Implementation UI Programming

Prism of Darkness is a dark fantasy turn-based combat title developed in Unreal Engine 5 by an 8-developer team. The project centers around tactical grid movement, synergistic spellcasting chains, and high-impact animated combat sequences.

  • System Designer: Architecting turn-order dynamics, action point economies, damage calculations, and character class ability trees.
  • Animation Implementation: Rigging gameplay state trees, hooking up combat montage notifies, root motion, and responsive hit-reactions in Unreal Engine 5.
  • UI Programming: Authoring intuitive Slate / UMG widgets for dynamic turn order timelines, skill selection wheel, and tactical status overlays.

Design Pillars & Technical Systems

Currently in active production, development is focused on tight combat feedback loops where tactical clarity meets atmospheric dark fantasy art direction. Further gameplay footage and breakdown videos will be published upon release.
